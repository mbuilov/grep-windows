Instructions how to build native pcre2 libraries and pcre2grep.exe utility using Microsoft Visual Studio (or Build Tools for Visual Studio) and WDK10.

From CYGWIN shell:

1) get archive:
  wget https://github.com/PCRE2Project/pcre2/releases/download/pcre2-10.49/pcre2-10.49.tar.gz
 or
  curl -LO https://github.com/PCRE2Project/pcre2/releases/download/pcre2-10.49/pcre2-10.49.tar.gz

2) unpack archive:
  tar xf pcre2-10.49.tar.gz

3) go to PCRE2 sources:
  cd pcre2-10.49

4) copy files
  cp ../pcre2/NMakefile-pcre2-10.49       ./NMakefile
  cp ../pcre2/config-pcre2-10.49.h        ./src/config.h
  cp ./src/pcre2.h.generic                ./src/pcre2.h
  cp ./src/pcre2_chartables.c.dist        ./src/pcre2_chartables.c

  --tip: ../pcre2/config-pcre2-10.49.h was generated by the configure script:
   1) open cmd.exe
   2) run vcvars.bat
   3) run c:\cygwin64\bin\bash
   4) export PATH="$PATH:/usr/bin"
   5) cd pcre2-10.49
   6) CC=cl ./configure --enable-jit --disable-shared
   7) use src/config.h

5) now start dos prompt with minimal environment (inherit TMP variable value):
  env -i TMP="$(cmd.exe /c set TMP | sed 's/.*=//;s/\x0d//')" $(which cmd.exe) /c start cmd.exe

In the dos window:

6) prepare environment, change console code page to ACP (Ansi Code Page):
  set "PATH=C:\Windows\System32;C:\WINDOWS;C:\WINDOWS\System32\Wbem;C:\WINDOWS\System32\WindowsPowerShell\v1.0"
  set LC_CTYPE=
  FOR /F "tokens=3" %F IN ('"reg query HKLM\SYSTEM\CurrentControlSet\Control\Nls\CodePage /v ACP"') DO chcp %F
  set VSCMD_SKIP_SENDTELEMETRY=1

7) setup compiler:
  "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvarsall.bat" amd64
  (if Microsoft Build Tools for Visual Studio 2022 is installed in "C:\Program Files (x86)")

  --tip: to build 32-bit version of PCRE2 library and pcre2grep.exe utility, specify "x86" instead of "amd64"
  (note: Microsoft dropped support for old OSes like WindowsXP in newer build tools)

8) build pcre2.a, pcre2posix.a and pcre2grep.exe, run tests:
  nmake -f NMakefile check

  --tip: it is possible to test pre-built pcre2 executables on a target machine, for this:
   1) unpack and copy archive of pcre2 sources to the target machine
    (to a path without spaces, otherwise RunGrepTest.bat fails)
   2) copy pre-built executables to the unpacked sources directory on the target machine:
    pcre2grep.exe           (use pcre2grep-10.49-x86.exe or pcre2grep-10.49-x64.exe)
    pcre2test.exe           (from pcre_test_x86 or pcre_test_x64 directory)
    pcre2_jit_test.exe      (from pcre_test_x86 or pcre_test_x64 directory)
    pcre2posix_test.exe     (from pcre_test_x86 or pcre_test_x64 directory)
   3) open cmd.exe window, go to the unpacked sources directory on the target machine
   4) prepare environment, change console code page to ACP (Ansi Code Page):
    set LC_CTYPE=
    FOR /F "tokens=3" %F IN ('"reg query HKLM\SYSTEM\CurrentControlSet\Control\Nls\CodePage /v ACP"') DO chcp %F
   5) run tests:
    cmd /c RunTest.bat && cmd /c RunGrepTest.bat && echo.All OK
